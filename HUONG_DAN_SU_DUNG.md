# ProLearning — Hướng dẫn dùng thử

Cảm ơn bạn đã dành thời gian trải nghiệm ProLearning 🙌 Đây là nền tảng hỗ trợ học tập và ôn luyện kiến thức, giúp gom **ghi chú, flashcard, đề thi** vào một chỗ, có AI hỗ trợ tạo nội dung. Chỉ cần vài phút là bạn có thể thử hết các tính năng chính bên dưới.

**Link truy cập:** https://prolearning.io.vn/

## Tóm tắt tính năng

| Tính năng               | Thử gì                                                                                   |
| ----------------------- | ---------------------------------------------------------------------------------------- |
| **Đăng ký / Đăng nhập** | Tạo tài khoản, vào Dashboard xem tổng quan tiến độ                                       |
| **Set Library**         | Tạo 1 Study Set (thủ công hoặc để AI tạo giúp từ 1 chủ đề)                               |
| **Flashcard**           | Học 1 bộ flashcard (tương tự Quizlet)                                                    |
| **Exam**                | Làm 1 đề thi, xem kết quả, có AI Explain kết quả                                         |
| **Note (cộng tác)**     | Soạn ghi chú, mời người khác vào chỉnh sửa cùng lúc real-time (tương tự Notion, GG Docs) |
| **Pomodoro Timer**      | Bấm chạy 1 phiên học, xem widget đếm giờ nổi góc màn hình                                |
| **Todo**                | Thêm vài task gắn với việc học                                                           |
| **Roadmap**             | Xem lộ trình học có sẵn, theo dõi tiến độ                                                |
| **Review Bundle**       | Ôn tập tổng hợp Flashcard đã làm sai trong tuần                                          |
| **Social Feed**         | Xem Resource công khai                                                                   |
