\subsubsection{Admin \& Moderation Context}
\label{subsubsec:admin-moderation-context}

Admin \& Moderation Context cung cấp chức năng quản trị nền tảng và xử lý các tình huống cần can thiệp của quản trị viên.

\begin{itemize}
    \item \textbf{User management:} Quản lý trạng thái tài khoản, khóa/mở khóa tài khoản và theo dõi thông tin người dùng.
    \item \textbf{Onboarding analytics:} Tổng hợp dữ liệu onboarding để đánh giá nhóm người dùng và nhu cầu học tập.
    \item \textbf{Appeal workflow:} Xử lý yêu cầu khiếu nại hoặc yêu cầu mở khóa tài khoản.
\end{itemize}
