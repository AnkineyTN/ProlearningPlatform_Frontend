\subsubsection{AI Service Context}
\label{subsubsec:ai-service-context}

AI Service Context đại diện cho dịch vụ AI độc lập do nhóm phát triển. Spring Boot backend gọi AI Service thông qua API nội bộ, sau đó parse kết quả và lưu vào các domain tương ứng.

\begin{itemize}
    \item \textbf{Ranh giới trách nhiệm:} AI Service tập trung vào xử lý ngôn ngữ và sinh nội dung; backend tập trung vào quyền truy cập, workflow nghiệp vụ và lưu trữ.
    \item \textbf{Kiểu request:} Hỗ trợ JSON request cho note/web/analysis và multipart request cho file upload.
    \item \textbf{Lợi ích triển khai:} Thành phần AI có thể được nâng cấp hoặc thay đổi mô hình mà không làm thay đổi cấu trúc dữ liệu lõi của backend.
\end{itemize}
