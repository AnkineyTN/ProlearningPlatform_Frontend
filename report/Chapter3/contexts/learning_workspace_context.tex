\subsubsection{Learning Workspace Context}
\label{subsubsec:learning-workspace-context}

Learning Workspace là bounded context trung tâm của hệ thống, quản lý cấu trúc học liệu và các hoạt động học tập chính. Context này liên kết người dùng với set, note, flashcard, exam và các tài nguyên phụ trợ.

\begin{itemize}
    \item \textbf{Tài nguyên học tập:} Set, note, note image/document, note explain, note file region comment, flashcard, card item, exam, question và exam attempt.
    \item \textbf{Tổ chức dữ liệu:} Học liệu được gom theo set để người dùng quản lý nội dung học theo chủ đề hoặc mục tiêu.
    \item \textbf{Chia sẻ:} Các tài nguyên có thể được mời thành viên, phân quyền và truy cập qua cơ chế membership.
    \item \textbf{Lưu trữ:} Dữ liệu quan hệ được ánh xạ bằng Spring Data JPA và lưu ở PostgreSQL~\cite{springdatajpa,postgresqlabout}.
\end{itemize}
