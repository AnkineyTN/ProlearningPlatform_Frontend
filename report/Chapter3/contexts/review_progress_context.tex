\subsubsection{Review, Knowledge \& Progress Context}
\label{subsubsec:review-progress-context}

Review, Knowledge \& Progress Context phụ trách ôn tập, ghi nhận kết quả học và phân tích mức độ nắm kiến thức. Đây là context giúp hệ thống chuyển từ lưu trữ học liệu sang hỗ trợ học tập thích ứng.

\begin{itemize}
    \item \textbf{Flashcard review:} Quản lý lịch ôn tập, study session, review log và thuật toán spaced repetition.
    \item \textbf{Knowledge analysis:} Gán topic, tính độ chính xác theo topic và lưu kết quả phân tích.
    \item \textbf{Progress tracking:} Kết hợp activity log, resource view log và review bundle để theo dõi hành vi học tập.
\end{itemize}
