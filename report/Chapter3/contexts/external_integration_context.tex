\subsubsection{External Integration Layer}
\label{subsubsec:external-integration-context}

External Integration Layer là nhóm adapter kết nối backend với dịch vụ bên ngoài. Backend giữ vai trò trung gian để bảo vệ khóa tích hợp, chuẩn hóa request/response và lưu lại kết quả quan trọng vào hệ thống.

\begin{itemize}
    \item \textbf{Cloudinary:} Lưu trữ ảnh, tài liệu và media thông qua signed upload hoặc upload từ URL~\cite{cloudinaryjava}.
    \item \textbf{Firebase Cloud Messaging:} Gửi push notification tới thiết bị người dùng~\cite{firebasefcm}.
    \item \textbf{Google OAuth/Calendar:} Hỗ trợ đăng nhập Google và đồng bộ todo với lịch cá nhân~\cite{googlecalendarjava}.
    \item \textbf{PayOS and SMTP:} PayOS xử lý thanh toán; SMTP provider xử lý gửi email giao dịch và tài khoản~\cite{payoswebhook}.
\end{itemize}
